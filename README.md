Velvet Vault — a museum heist game. You are the thief: cross four galleries, dodge five patrolling guards (including elite Rosa and roaming Felix) and five sweeping cameras, time the laser grids, pocket eight treasures worth $1,680, and slip out the getaway door before the alarm meter hits 100. Coins distract guards, smoke blinds them, an EMP kills the cameras, silent shoes buy speed. Finish fast and quiet for a 3-star getaway.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.
